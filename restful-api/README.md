# RESTful API - Python

This repository contains Python scripts developed as part of the Holberton School software engineering curriculum, focusing on consuming and processing data from web services and APIs using Python.

---

## Technologies & Tools
* **Python 3.8.5**
* **Requests Library** (HTTP communication)
* **CSV Module** (Data structuring and export)
* **Git & GitHub**

---

## Project Tasks & Files

| Task File | Description |
| :--- | :--- |
| `task_02_requests.py` | Python script to fetch posts from JSONPlaceholder API, print status codes/titles, and save filtered data (`id`, `title`, `body`) into a CSV file (`posts.csv`). |
